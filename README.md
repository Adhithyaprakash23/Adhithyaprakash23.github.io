# Adhithya Tatineni Prakash — Security Engineering Portfolio

A recruiter-focused cybersecurity portfolio designed around **evidence of security work**, not a generic skills list.

## Included
- Responsive single-page portfolio
- Interactive SOC investigation
- Security case-file modals
- AegisCloud and Enterprise SOC Detection Engineering Lab links
- Security Engineering, Detection & Response, Cloud Security, Vulnerability/AppSec, Automation, and Governance capability sections
- GitHub Pages-compatible static HTML/CSS/JavaScript
- Accessibility support including reduced-motion behavior

## Publish for free with GitHub Pages

Copy `index.html`, `styles.css`, and `script.js` into the root of your `Adhithyaprakash23.github.io` repository, commit, and push to `main`. GitHub Pages will serve the site from your existing Pages domain.

## Before publishing

1. Replace the role-focused Experience section with your **exact verified employer names, titles, dates, and responsibilities**.
2. Add your preferred public email only if you want it exposed.
3. Add a resume PDF and a Resume button if desired.
4. Add screenshots/architecture diagrams to project case files as your repositories mature.
5. Never publish confidential employer/client data, credentials, internal screenshots, proprietary queries, or sensitive incident details.

## Design rationale

The portfolio emphasizes case studies, measurable security decisions, interactive technical demonstrations, responsive UX, accessibility, SEO metadata, and direct evidence links. This structure is inspired by strong public cybersecurity portfolios, while the visual design and copy are original.
