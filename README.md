# Adhithya Tatineni Prakash — Cybersecurity Portfolio

A dependency-free, GitHub-Pages-ready cybersecurity portfolio.

## Why this version is stronger

- No external logo CDN: tool icons render locally, so the missing-logo problem is removed.
- Responsive desktop/mobile layout.
- Interactive security tool filters and experience modals.
- Interactive project case studies.
- Animated SOC signal visualization and telemetry terminal.
- Keyboard command palette: `Ctrl/Cmd + K` or `/`.
- Scroll progress and reveal animations.
- Respects `prefers-reduced-motion`.
- Semantic HTML and keyboard-accessible cards.
- No framework/build process required.

## Deploy to your existing GitHub Pages site

1. Back up the current repository.
2. Replace the current site files with:
   - `index.html`
   - `styles.css`
   - `app.js`
3. Commit and push:

```bash
git add .
git commit -m "Upgrade portfolio to interactive cybersecurity experience"
git push
```

GitHub Pages should publish the update automatically.

## Recommended optional final step

Add your real resume as `resume.pdf`, then add a "Download Resume" link in the hero. Do not publish a placeholder or outdated resume.
